# DeepTrace

Research on dependency graphs, temporal changes, and selecting relevant evidence for security monitors.

## Project files

- `research/agentsecgraph/`: graph analysis, research notes, scripts, and visualizations.
- `research/deeptrace_experiments/`: temporal graph experiments, monitor evaluation, and results.
- `output/`: reports and presentations.

Downloaded upstream repositories, datasets, model weights, local environments, credentials, and temporary files are excluded. See the research notes and reproduction instructions in each research directory for setup and experiment details.
